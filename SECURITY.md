# Security Policy

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues or discussions. Use the
repository's private security advisory form and include affected routes,
reproduction steps, impact, and a minimal proof of concept when safe.

Do not include real credentials, personal data, or production secrets. The
maintainer will acknowledge a complete report as soon as practical, validate
the impact, and coordinate remediation and disclosure.

Only the latest deployed revision is supported with security fixes.
